# 今日动态与周报一致性修复

本批只修阅读投影，不改变采集预算、请求恢复、评级历史或外发设置。

- 今日动态和周报使用同一可靠事件日期（兼容已有 Agent 报道日期），不以收录时间填日期。校验真实日历日期，按时间戳处理时区偏移，排除未来日期。
- 页面显示期间内事件数、待评级、日期待核和期间外数量；空状态复用现有 monitoring progress。普通资讯继续在今日动态展示，周报仍汇总重要事件与新资料，不自动提升评级。
- 已有事件的内容、评级、日期、来源与状态变更也提示更新。用户点击才应用新快照；本地标记操作清除待更新快照，避免覆盖人工状态。
- 周报及 Markdown 是已存结果的本地只读聚合，没有启动模型的必要。外发配置、人工推送和自动推送均不改变。重复打开不生成研究任务、不新增模型费用。
- 回归覆盖日期未知、旧资料新收录、未来/无效日期、时区边界、普通/待评级、任务失败、同 ID 修订及导出一致性。真实读取与合成验收分别记录，不声称完成真实语义质量或连续在线验收。
