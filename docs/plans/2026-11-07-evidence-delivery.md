# Evidence delivery repair plan

**Goal:** Make existing attributed material available to relationship monitoring and downstream judgments without promoting unsupported claims or replaying unresolved requests.

**Architecture:** Reuse the existing immutable facts and source lifecycle. Repair identity validation and fact dependency propagation; project current commercial assertions into the existing monitoring plan. Keep candidate research separate from a supported competitive verdict.

**Tech stack:** Python, SQLite, React/TypeScript; offline synthetic regression and private snapshot replay.

1. Reproduce company identity failure with a user-confirmed company and a source-backed owned product. Resolve identity from scoped current product references; test foreign/withdrawn/private evidence rejection.
2. Reproduce source-reference enrichment invalidating previously accepted product facts. Preserve facts on additive reference changes only; retain invalidation on name, parent, alias, visibility and evidence changes.
3. Connect current source-backed business relationships to standing monitoring, idempotently and without restoring user-retired entries. Preserve pilot/cooperation roles; never relabel them as revenue or orders. Use the same alias binding as business extraction.
4. Stop identical automatic relationship assessments from repeatedly invalidating judgments. Keep correction history and invalidate on actual interpretation changes.
5. Replay saved private material offline, inspect counts and reasons; no network, provider retry or live database write. Add cross-project synthetic negative cases.
6. Run focused regressions, broader affected suite, lint, Node tests, wheel correspondence and fresh-install smoke. One independent strongest-model review; repair confirmed findings. Preserve live running work, data, configuration and unresolved request receipts.

Completion requires evidence-backed outputs and reported residual missing material, not fabricated nonzero counts or forced positive judgments. Public release is out of scope.
