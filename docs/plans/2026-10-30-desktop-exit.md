# 桌面安全退出

页面和本地维护命令复用托盘的 ExitRequest。退出先调用原 drain：阻止新的写入及工作领取，等待当前工作与写入结束，由 Uvicorn 正常生命周期关闭后台，再结束托盘。保留暂停设置、数据、请求和恢复回执；无 kill、超时强退、自动重试或重新启动。

仅桌面进程注册 `/api/desktop/exit`；POST JSON 必须匹配当前随机实例身份，沿用 localhost Host 和同源校验。身份过期、旧版本、其他服务、无 endpoint 或失败均不尝试强制停止。服务器/源码普通 web 模式不出现按钮。

左下角提供“退出 ProjectWatch”；本地维护使用运行环境的 `python -m project_watch.studio.desktop --home <数据目录> --request-exit`。返回 `exit_requested` 只表示请求已接受，维护工具须继续确认 endpoint 消失、桌面会话锁和资料目录锁可取得、相关实例进程已结束，才能开始升级。端口不可访问不等于后台退出。工具不得把旧实例确认用到新实例。

验证覆盖同源/跨源和错误身份、重复退出、请求先 drain、没有桌面时不启动新实例、实际服务等待在途写请求退出，以及退出后锁释放与数据保存。使用合成数据，不对现用实例执行验证，不新增模型调用。
