# 判断页流程隔离（2026-11-10）

仅处理流程，不调整模型评级、提示词或证据核验标准。

- 新的安全接入任务冻结逐页交付协议：每页完成引用支持、完整快照反证及与已展示栏目的一致性后发布，再处理下一页。
- 页面遇到 unknown 记录永久阻塞回执；其他独立页面继续，后续累积草稿不得重新请求该页的未决核验。
- 每页对照版本及结果持久保存，任务让出或重启后复用，保留旧发布头。
- 已冻结模式、已发起共享核验、历史 unknown/started 和未允许恢复的模型 5xx 不自动切换请求格式。
- 旧任务仍沿原检查点接续；本次不宣称北启旧任务已完成迁移或分析。旧共享未决请求不能以拆页绕过。

验收：独立页面先显示、同级失败隔离、不同草稿不能绕过未知、发布与阻塞标记间中断可恢复、跨页矛盾仍拦截、全来源反证仍覆盖。无真实调用与实例变更。
