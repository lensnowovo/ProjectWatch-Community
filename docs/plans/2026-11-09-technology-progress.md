# 技术进展入口

外部信息保留公司进展、竞品动态、产业链动态、宏观环境，并增加技术进展入口。技术进展聚合已有技术摘要、技术方向判断及关联报道，论文、专利与注册和适用企业的临床进展作为子分类。

沿用现有技术摘要与证据，不在浏览器生成新事实或按公司名称硬编码行业。临床使用已保存的医疗监控方案、申办方或已有临床材料判断适用性；适用但零条仍可进入。不适用企业不显示临床分类。历史 trials / papers / patents 链接保持可读，并选中技术进展父入口。

不改数据库、模型请求协议、采集调度或旧 unknown。本次复用已有技术分析内容，不代表新增了各行业的专项采集器。宏观环境的技术监控保留为原有路线观察入口。

真实页面核对：非医疗标记下与公司名完全相同的旧申办方默认值不再作为临床适用依据。实际临床来源、登记记录、临床检索词或其他申办方仍保留入口。历史临床直达链接不变。
