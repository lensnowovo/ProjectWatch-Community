# One fixed material after a terminal partial round

This is an explicit maintenance path, not a new scheduler, public recovery API,
automatic retry, or a new research round. A caller reviews and freezes one
unattempted paper task, its current public evidence version and stable source ID.
The company association must be supported by the saved source and still pass the
normal semantic reviewer; being returned by search does not establish attribution.

`material_once.plan` is read only. `begin` compares that exact baseline in an
immediate transaction, rejects unresolved calls, other project work and consumed
starts, appends the original terminal job snapshot, and takes the normal job lease
for at most 90 minutes. It never queues a second job or creates a fresh balance.
The frozen material cap and original journal remain authoritative. The selected
extractor can send at most one new model request; the whole continuation at most
two. Search, page, open-data and site calls are denied. Lower original limits win.

New research checkpoints use a separate deterministic namespace in the same job.
Old completed state, closeouts, rejected material results and call receipts stay
byte-identical. Only the fixed task is processed. A length result, invalid
candidate, unknown, source withdrawal, changed evidence, pause or expired/replaced
lease stops work. More than one required admission batch also stops without
discarding the proposal. No second source is selected. The ordinary semantic
reviewer must accept all proposed assertions before the existing publisher runs;
the publisher reuses that exact review, with no further provider request.

The completion receipt is separate from the original terminal result. The original
job row is restored only while the continuation still owns its lease token. A
crash keeps its consumed start/lease and all request receipts; it cannot be
automatically restarted. An operator must inspect the evidence, never remove the
start record or infer that a timeout was not charged.

This bounded path does not generate analysis, daily/weekly reports, obtain new
sources or claim a complete monitoring journey. One accepted paper is only a
partial result. A real invocation requires an independently reviewed exact script,
installed artifact, source/body hash, baseline digests, finite new window and
permanent once-only lock. Tests use isolated synthetic providers and native DSH;
passing them does not imply real model quality or real publication success.
