## 每次接受贡献的记录

以下是需要收集的字段，不是已完成的授权记录。个人资料及授权证明通过私密渠道保存，不放在公开仓库：

- 模板版本及全文哈希、接受授权主体、签署日期。
- 贡献者可核实的身份或代表权限；雇主/委托方授权是否适用。
- PR 地址、精确提交 SHA、文件/补丁范围及其哈希。
- 原创部分、第三方部分及原许可；必要专利是否存在待核事项。
- 明确同意语句、接受记录位置及维护者复核人。

公共 PR 可只记录“授权已核对”、模板版本和贡献提交范围；不公开签名、私人邮箱、单位证明或证件。
代码范围改变后复核授权覆盖；不要将一次同意扩展到未列明的未来贡献。
