# Windows 用户版验收

本页对应带“连接 Agent”入口及自定义安装目录的私有候选，不代表 GitHub 上的旧安装包已经更新。测试前先核对随包提供的 SHA-256。安装包尚未签名，可能显示“未知发布者”；若来源或哈希无法确认，不要继续。

## 安装

1. 双击 `ProjectWatch-Setup.exe`，阅读许可。
2. 选择是否创建桌面快捷方式，选择一个有写入权限的程序文件夹，例如 `D:\Apps\ProjectWatch`。不要选择现有资料文件夹或网络共享。
3. 安装完成后，从桌面或开始菜单打开 ProjectWatch。不需要 Python、Node 或终端。

程序和用户数据分开保存。资料、配置、Key 与 Agent 授权保存在 `%LOCALAPPDATA%\ProjectWatch-Desktop`，不随程序目录移动。更换程序安装位置请先卸载再安装；升级默认沿用已登记的位置。

## 两条路径分别测试

### 独立 API

1. 首次设置选择独立 API，填写一个模型和一个搜索服务。
2. 测试连接；真实测试会消耗相应服务额度。
3. 输入公司名，核对主体，开始监控；另建一个项目上传自己的 BP。
4. 确认任务状态、新闻来源及项目内容可以显示；失败应给出原因，不能伪装成“没有新闻”。

### 已有 Agent

1. 进入“连接 Agent”，新建一个项目；可上传材料，本地解析不调用模型或搜索。
2. 选择 Codex 或 WorkBuddy，确认项目级授权。只有需要分析 BP 时才勾选内部材料读取；这些材料可能发送给 Agent 的模型服务。
3. 把生成的 MCP 配置合并到所选客户端，保留原有条目，不要覆盖整份配置。重新载入 MCP。
4. 先让 Agent 读取项目，确认公司和实例正确，再使用页面提供的研究提示词。写入需由客户端批准时，请核对范围。
5. 检查新闻/简报写回、来源链接、关注点新增与关闭。关注点应包含检索词和退出条件。
6. 刷新 ProjectWatch，确认结果可见。新建 Agent 项目不会自动启动内置 API 监控；这是按需研究，不是无人值守调度。

Codex 已完成一轮原生读取、公开搜索、授权写回和关注点关闭测试。WorkBuddy 当前完成配置与 MCP 协议回归，原生客户端全流程仍待用户验收。生成配置不等于连接成功。

## 关闭、重开和卸载

- 关闭网页不等于停止后台进程；使用托盘菜单退出 ProjectWatch。
- 重开后检查项目、暂停状态、设置和资料仍在。
- Agent 连接需要 ProjectWatch 打开。重开后先读项目确认连接；升级或移动程序后重新生成 MCP 配置。
- 升级前退出 ProjectWatch；运行中的实例会阻止升级/卸载，不会被安装器强制结束。
- 卸载只移除程序及快捷方式，保留资料、配置和备份。重装后使用原数据；需要从零测试请换 Windows 账户或干净电脑，不要删除旧资料。
- 任何付费请求结果不明，先核对回执，不要反复点击或让 Agent 自动重试。
