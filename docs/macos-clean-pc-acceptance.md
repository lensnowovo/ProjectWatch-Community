# Apple Silicon Mac：干净电脑验收单

状态：验收步骤，**不是已通过报告**。本轮只验 M 系列 Mac，Intel 暂缓。使用维护者交付、带固定 SHA-256 的同一候选包；不要混用旧版下载。

## 开始前

- 记录测试者、日期、Mac 型号/芯片、macOS 版本、候选版本和 SHA-256；不填写账号密码。
- 电脑不预装 Python、Node、npm、Git 也应能使用。测试者按本文独立操作，记录所有需要求助的地方。
- 如已有 ProjectWatch 数据，先退出并备份；全新安装测试使用新的 macOS 用户账户，不能删除原数据来制造空环境。
- 模型、搜索、公开阅读的真实验收需先说明预计调用量并取得本轮同意。尚未获准时，仅进行安装、页面和离线合成测试，**不要点击服务测试或开始监控**。
- 当前候选可能未签名、未公证。遇到系统拦截，记录原始提示并交维护者判断可信启动路径；不要关闭 Gatekeeper/杀毒、安装根证书或执行来源不明命令。

## 维护者补充验收

这部分不要求普通使用者安装工具；由维护者在隔离测试环境完成，不能由 Windows 静态检查代替。

1. 用实际候选内的 Python 启动，核验 PyObjC / AppKit、菜单栏主线程、HTTPS 证书、OCR 原生扩展及 SQLite。
2. 用实际候选内的 Node 和 DSH 运行合成网关协议回归；禁止访问真实供应商，记录对外连接情况。明确测试宿主与被测运行时的来源。
3. 缺 Node、损坏 DSH、错误架构/权限时可见“不可用”，不静默降级；显式关闭 DSH 和自定义路径保留。仅破坏复制的合成应用，不操作用户安装。
4. 验证旧 Mac 候选升级至含 DSH 版本、设置关闭后的再次升级，记录执行方式变化及告知；不能只测全新目录。
5. 核对 ZIP 文件清单、每文件哈希、三处入口执行位、Mach-O/Python ABI；记录源码提交、依赖清单、版本与资产哈希。
6. 真实业务按 [固定完整验收](monitoring-acceptance-criteria.md) 执行。平台 smoke 不代表自然停止/新证据唤醒已经通过；已有 Agent 模式还须对应客户端实测。

## 回传与通过规则

只回传设备/版本、逐项结果、脱敏错误及经确认可公开的截图。不上传数据目录、数据库、API 配置、BP 或原始日志。安装问题使用 [反馈入口](../SUPPORT.md)，安全问题走私密渠道。

任一主路径阻断、数据变化、重复付费风险或核心状态误报都必须先修复。未获得付费授权、设备缺席或系统拦截未解决的项目记“未覆盖/阻断”，不能算通过。最终结论汇入 [发布准备状态](release-readiness.md)，原始回执私下保存，发布仍需维护者确认。
