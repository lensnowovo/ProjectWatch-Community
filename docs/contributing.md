# 参与开发

先阅读开发者安装指南、架构与已知边界。使用自己的独立环境和合成数据，
不在任何用户的真实实例上进行自动测试。

修改前明确问题、预期行为和回归用例。保留解析、存储、监控与已有分析能力，
不通过删掉失败测试、关闭分析或吞掉错误取得通过结果。
涉及持久化时保留迁移并执行升级/备份恢复演练；涉及外部调用时保留用量和未知结果保护。

提交前运行对应 Python、Node 和前端类型检查；安装相关修改验证新环境 wheel 安装。
在说明里分别列通过、失败、跳过和未覆盖，不能用配置存在代替真实执行证据。
不要提交 Key、真实材料、运行数据库、日志、备份、机器私有路径或生成的依赖目录。
任何新增依赖、字体、图像或改编代码必须记录来源和许可。

本版本自有代码适用根目录 ProjectWatch 社区使用许可 1.0；第三方部分保留原许可。
请先与维护者 lensnowovo@gmail.com 确认贡献范围和授权，再合入代码。贡献者保留版权，
不会默认为提交 PR 即同意版权转让或商业再许可。须逐次记录代码来源、具体提交及明确接受的协议版本；
雇员或受托开发者还需确认有权贡献。AI 辅助生成也不免除来源核查，不提交私人提示词和材料。

纳入商业版本需单独取得非独占商业再许可权；没有相应授权的贡献不得自动进入商业发行。
[贡献授权模板](contributor-authorization.md)正进行发布前审阅，未启用自动签署；不能把勾选普通 PR 检查清单当作协议签署。
合并、正式发布和变更仓库可见性由维护者明确批准。
