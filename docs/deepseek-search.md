# DeepSeek Search

搜索服务与模型服务分别配置。使用 DeepSeek Search 不要求更换当前模型，也不要求
删除博查、Tavily 或 Brave。API Key 仅保存在本机私有配置，界面返回掩码。

## 配置

设置 → 新闻与搜索 → 启用 DeepSeek Search，填写搜索 Key，保存后显式测试连接。
测试会调用已启用的搜索服务；保存、打开页面本身不会自动测试。
首次配置向导也可选择 DeepSeek Search。

自动模式：启用且有 Key 时 DeepSeek 优先；中文优先由博查补位，英文优先由 Tavily
补位。正常取得可用结果不会再调用所有来源。联合模式仍会调用所有已启用来源，
费用分别计算。不启用 DeepSeek 的旧配置保持原有路径。
明确无结果/失败可补位，网络结果不明或请求锁定会停止，不能用换源绕过恢复确认。

## 正文与 DSH

通过既有搜索网关调用官方 `/v1/tools/search`，使用 `need_content=true`。
查询不发送内部原件或用户完整原始问题。搜索全文随回执/项目内缓存保存，不默认
将全部正文塞进模型上下文。DSH `pw_read` 每段最多 12000 字符，通过 `next_offset`
按需继续；完整返回内容保留在本地。无缓存正文时，可经同一请求日志调用
`/v1/tools/fetch`；已知读取失败保留原因及可用摘要，不能伪称完整原文。

供应商的日期、权威性和排序分只是检索元数据，不自动成为事件时间、报告期或
真实性认证。同文档不同 fragment 保留定位并去重。

## 用量和故障

Search 按 search、Fetch 按 page、模型按 model 分别记录；即使三者同域名也不混计。
page 可能同时包含现有公开阅读器，请结合供应商指纹区分，不能把所有 page 都当作
DeepSeek 计费次数。成功回执可重放，结果不明不自动重试。实际账单以供应商为准。

官方说明：https://api-docs.deepseek.com/zh-cn/guides/search/

这是隔离候选功能。DSH 运行时仍按现有 opt-in 方式部署；本次源码集成不代表
已经升级用户桌面实例或捆绑 Node/DSH 安装包。
