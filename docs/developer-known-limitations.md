# 开发者预览版的已知边界

- 当前为开发者预览，不是稳定生产版本。完整源码可用；机构内部自用免费，对外商业服务须按 LICENSE 取得授权。
- 公共信息的覆盖和准确性取决于来源与模型。监控结论不是对未披露财务或投资结果的保证。
- 模型/搜索/商业服务使用自己的账号，费用不包含在源码中；无效 Key、额度不足或断网会阻止相应任务。
- 完整源码包含已有分析，但是否能得到有效结论仍取决于材料，不为缺失证据填造指标。
- 合成回归验证流程与防护，不等于某个具体公司的所有分析均已获得人工认可。
- 个人 SQLite 是主要交付路径；PostgreSQL/team 需要独立部署与验收。
- OCR、MCP 是可选依赖；安装可用与真实外部客户端授权、不同材料质量的验证分开记录。
- 本机服务和 Vite 开发服务器不应直接暴露公网；当前候选不是多租户云服务。
- 备份包含密钥与原件，须私密保存；升级前验证备份，并保留旧环境供回滚。
- 首次安装需要获取依赖；没有离线依赖包时不能承诺无网安装。
- 软件更新器只接受稳定标签；预览版需独立下载安装或由 Agent 协助升级。

提交问题时提供版本、脱敏复现步骤和错误码；不要附实际 BP、Token 或整个数据库。
