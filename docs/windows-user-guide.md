# Windows 使用指南

适用于当前 Windows x64 桌面候选。尚未正式公开发布；请只使用维护者提供且哈希可核对的候选，或正式 Release 中明确列出的 Windows 安装器。不要把旧 alpha 的源码 ZIP 当成安装包。

## 1. 安装并打开

下载 `ProjectWatch-Setup.exe`，核对版本与随包 SHA-256，然后双击。可选择有写入权限的程序文件夹和桌面快捷方式；不要选择自己的资料目录、源码目录或网络共享。安装后从桌面或开始菜单打开，浏览器会连接本机服务。不需自行安装 Python / Node，也不需打开终端。

安装器目前未签名，可能出现未知发布者或系统拦截。来源、哈希不明确就暂停。不要关闭 Defender、Smart App Control，不要安装自签根证书；把脱敏后的提示交给维护者核查。无告警也不代表包已经过签名认证。

## 2. 选择使用方式

| 方式 | 要准备什么 | 适用情况 |
| --- | --- | --- |
| 独立 API | 自己的模型账号/Key 与一个搜索服务账号/Key | 需要 ProjectWatch 后台持续监控 |
| 连接已有 Agent | 已有 Codex 或 WorkBuddy，以及该客户端的使用权限 | 让 Agent 按项目授权读取、研究、写回和调整范围 |

API 模式在设置中填写服务和模型，保存后按提示测试连接。连接测试和真实研究可能计费；一个 Key 不一定同时拥有模型与搜索权限。商业数据来源是可选项，不是首次使用的必填项，启用前核对自己的许可与额度。

Agent 模式从“连接 Agent”进入，按页面生成的 MCP 配置连接客户端。保留客户端其他配置，确认实例和项目后再授权写入。只有确实需要分析内部材料时才授权相应读取；内容可能发送至 Agent 的模型服务。ProjectWatch 必须保持打开。生成配置不等于客户端已连通，按需 Agent 研究也不等同无人值守 API 监控。

## 3. 建立第一个项目

输入公司名或上传获准使用的 BP，核对主体再确认。名称相同不代表同一家公司，先看公司全称、所在地等识别信息。不要为了让流程继续而强行确认错误主体。

任务运行时查看阶段和已有产出，之后核对项目档案、公开来源、关联监控与判断。部分完成意味着已有结果保留但仍有缺口，不等于所有来源失败，也不等于已经全量覆盖。报告期、披露状态和意向订单等限定应保留；重要结论仍要打开来源核实。

长期关联持续关注“因为什么而关注什么”；临时研究可以结束，之后由符合条件的新证据唤醒。穿透概览中的层级只表示目前各方向走到多深，不保证该层所有对象已覆盖。

## 4. 暂停、退出和重开

- 不想继续发起监控任务时，使用项目的暂停控制；暂停不保证撤回已发给外部服务的请求。
- 关闭网页不会关闭后台。需要退出时，从 Windows 托盘选择“退出（等待任务结束）”，给在途任务留出收尾时间。
- 重新打开后检查项目、配置、原件和暂停状态仍在。桌面入口使用本机动态端口，不要把某次端口当永久地址。
- DSH 运行时缺失会显示不可用；不要手工把不匹配版本复制进程序目录，也不要删回执绕过阻断。

## 5. 升级与备份

当前桌面版采用**下载已核对的新安装器、正常退出后安装**的受控升级方式，不承诺后台自动下载并替换程序。设置中的源码 Git 检查不能替代桌面安装器升级；如果提示未配置源码更新源，不要给安装版手工初始化 Git 仓库。

先等任务收尾、正常退出，再用新安装器升级到已登记的位置。安装器应拒绝覆盖运行中的实例；不要强制杀进程或先删除旧目录。升级保留用户数据和配置，并生成备份。更换程序位置与升级不是同一步，需按卸载重装说明操作，不能把唯一数据一起移动或删除。

在资源管理器地址栏可以查看：

- 默认程序目录：`%LOCALAPPDATA%\Programs\ProjectWatch`（自定义安装则以所选位置为准）。
- 数据、原件、配置和授权：`%LOCALAPPDATA%\ProjectWatch-Desktop`。
- 默认升级备份：`%LOCALAPPDATA%\ProjectWatch-Desktop-backups`。

备份含敏感配置和资料，不要上传公开工单。需要恢复时先在独立目录验证与版本的兼容性；不要将旧备份覆盖正在使用的数据目录，不要只换旧程序去打开新数据库。

卸载移除程序、运行时和快捷方式，用户数据与备份保留。清单内的程序文件即使被本地改过也会删除，定制代码应提前另存；这不是用户资料的存放位置。重装会复用保留的数据。干净首次使用应换 Windows 账户或电脑，不要为了测试删除现有资料。

## 6. 遇到问题

| 现象 | 先做什么 |
| --- | --- |
| 请求结果不明／待确认 | 不反复点重试、不换新任务绕过；保留回执，核对服务商记录与恢复范围。未知用量不能按零计 |
| 部分来源不可用 | 看已保留的结果和具体缺口，区分账号权限、限额、网络与来源无数据 |
| 页面显示失败但有产出 | 记录任务阶段、发生时间、版本及脱敏错误，不删项目重新跑来掩盖问题 |
| 安装/启动被系统拦截 | 核对来源、版本和哈希，记录安全提示；不关闭系统保护 |
| 发现事实或报告期错误 | 附公开/合成来源和预期限定，不上传 BP、完整数据库或商业原文 |

反馈入口与脱敏要求见 [SUPPORT](../SUPPORT.md)。软件不自动上传诊断数据，也不附送任何服务 Key。
