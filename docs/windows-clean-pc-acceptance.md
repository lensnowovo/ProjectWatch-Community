# Windows 用户版：干净电脑验收

仅供独立用户私下验收，尚未发布。当前准备版本为 **0.2.0rc2**，最终安装包与
SHA-256 尚未冻结；以维护者随包提供的清单为准，不使用历史 0.2.0a1 候选代替。
密封隔离测试安装器不能交给普通用户。收到标准安装包之后再按本表开始。

维护者已确认可安排朋友或另一台 Windows 电脑。本表由试用者独立执行；记录需要
求助的位置，不由开发者代操作后填为“首次使用通过”。

## 准备

- 优先 Windows 11 x64，普通用户账号，预留至少 5 GB 空间及资料/升级备份空间；无需安装 Python、Node、Git。
  若只能提供 Windows 10，先记录具体版本及系统支持状态，按[支持矩阵](release-support-matrix.md)
  核对，不提前计为已支持；不使用 Windows ARM 或 Server 代替本轮目标电脑。
- 一个有额度且允许此用途的模型 API、一个受支持的公开搜索服务（DeepSeek Search/博查/Tavily/Brave）。不要把 Key 发回聊天。
- 安装与打开不产生真实研究调用；保存并测试连接、确认公司或提交分析前，先核对该次预计调用量和接受的费用范围。未知结果先停，不反复点击恢复。
- 把整个验收 ZIP 复制过去，在普通本地文件夹解压；不要在 ZIP 内直接运行。
- 安装器尚未签名。若遇到拦截，记录完整提示，先暂停；不要关闭 Defender、Smart App Control 或安装自签根证书。
- 只用自己的测试资料。模型分析会按授权发送相应内容给配置的模型服务；安装包不包含任何人的 Key、真实 BP 或项目库。

## 按顺序测试

| 编号 | 操作 | 预期与记录 |
|---|---|---|
| 01 | 双击 ProjectWatch-Setup.exe，自选本地目录（可含中文和空格），保留桌面快捷方式 | 无需管理员、Python 或终端；记录安全提示、安装耗时和安装目录；不改已有软件目录 |
| 02 | 从桌面打开 | 自动打开本机浏览器，出现首次配置页，托盘有图标；记录耗时 |
| 03 | 选一个模型与一个搜索，填自己的 Key，同意后点“保存并测试连接” | 各自结果明确；测试会消耗服务额度。结果不明时不要反复点击，先核对服务商记录 |
| 04 | 按随包本轮预算说明，添加一个公开公司并确认正确主体 | 首轮任务能启动并结束，看到来源与结果；明确完成/部分完成/待确认，不能只看动效。记录首轮耗时、实际用量、人员/产品/竞争与行业的覆盖和具体缺口 |
| 05 | 暂停该项目，再添加/上传验收包中的合成 BP.txt | 确认这是虚构测试公司；应读出产品、行业与材料日期。不要用它判断真实新闻质量；不要强行确认错误的真实公司 |
| 06 | 关闭浏览器，再次双击快捷方式 | 回到已有实例/项目，不重复创建项目；关闭网页不等于后台退出 |
| 07 | 等在途任务结束，将所有测试项目暂停，从托盘退出，再重新打开 | 项目、材料、配置和暂停状态还在，不需要重新填 Key |
| 08 | 程序运行时再次打开安装器 | 拒绝覆盖运行中程序，不杀进程；退出后重跑同一安装器应保留数据并生成备份 |
| 09 | 托盘退出后，从 Windows 设置 → 应用卸载 ProjectWatch | 快捷方式移除，资料和配置保留；不要手动删除数据文件夹 |
| 10 | 重装同一安装器，从快捷方式打开 | 原项目、材料、Key 配置和暂停状态仍在。核对后保持暂停并从托盘退出 |

第 08 是同版本维护安装，不代替真正跨版本升级。RC2 安装器生命周期验证以当前
[发布准备状态](release-readiness.md)及维护者提供的对应验收摘要为准，不能继承旧候选的通过结论。
若首轮在持续请求而没有进展，先截图任务状态并暂停后续调度；不要强制结束正在计费的请求。

## 补充测试（可以第二轮再做）

- 断网后启动：界面应可打开，原数据仍可见；联网服务应明确失败，不能假装更新成功。恢复网络不代表可以重试结果不明的付费请求。
- 睡眠与恢复：先等在途任务结束、暂停所有测试项目，保持应用打开，让测试电脑睡眠后唤醒。检查页面能重新连接、暂停状态未变、没有新增研究调用；记录睡眠前后时间和异常提示。不用模拟时钟测试代替这项实机结果。
- 系统重启：同样先结束在途任务并暂停项目，从托盘退出，再正常重启测试电脑。手动打开桌面快捷方式，检查项目、配置和暂停状态保留；不要求开机自动运行，也不要在请求计费期间强制关机。
- 公开监控执行器：新安装自带 DSH/Node，不要求自行安装。设置中应能看到实际可用状态；显式开关在正常退出后重开生效。缺运行时应明确不可用，不能偷偷切换执行方式。
- 已有 Agent：若试用者有 Codex/WorkBuddy，按连接说明先验读取与拒绝写入；通过客户端审批后再做隔离项目写回。没有该客户端记“未测”，服务端协议通过不代替客户端验收。
- 扫描 PDF/图片：本候选已含默认中文 OCR 三份模型，合成图片在禁用 Python 网络连接后识别通过。其他语言/字体/模型可能另需下载。先测文本 BP，再单独记录真实扫描件结果；合成图片通过不等于所有扫描 PDF 均已验收。

## 文件位置

在资源管理器地址栏粘贴即可，不需要终端：

- 程序：`%LOCALAPPDATA%\Programs\ProjectWatch`
- 资料、配置、原件：`%LOCALAPPDATA%\ProjectWatch-Desktop`
- 升级备份：`%LOCALAPPDATA%\ProjectWatch-Desktop-backups`

这些目录可能含 Key 与私有材料，不要整包发送。旧开发者版目录不会被自动导入；本次不要将旧真实数据混入测试。
