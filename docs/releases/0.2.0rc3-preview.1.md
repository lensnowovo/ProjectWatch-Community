# ProjectWatch 0.2.0rc3 Windows 公开预览

版本：`0.2.0rc3`。平台：Windows x64。维护者已授权本次公开预览，下载以 [`v0.2.0rc3-preview.1` Release](https://github.com/lensnowovo/ProjectWatch-Community/releases/tag/v0.2.0rc3-preview.1) 实际展示的附件为准。Mac 新版本暂缓，旧 Release 和 Mac 资产保留，不替换为本次 Windows 的验证结果。

这是架构重构后的预览版。它已经过本地故障、安装态及远程 CI 验证，仍有下面列出的真实质量和使用环境限制，不作为完整监控验收通过的稳定版。

## 本次变化

- 公开来源采集、正文补读、材料提取、事件整理和影响分析分阶段保存。来源可以先出现，分析逐步补齐；下游失败保留已完成的来源和回执。
- 范围维护、问题评估和基础监听独立推进，问题在连续无增量后休眠，并可因新证据或纠错唤醒。
- 后续阶段共用轮次预算，保留证据版本、人工保护、任务归属和恢复记录。结果不明的请求保持停止状态，不能通过重建任务绕过。
- 修复候选 R2 暴露的旧数据库升级初始化问题；后继 R4 已验证旧库升级、原有来源及事件状态保留和重复打开。
- 固定受影响的解析及 DSH 传递依赖，随包提供原始许可和对应第三方源码。

## 验证及其边界

[完整远程 CI](https://github.com/lensnowovo/ProjectWatch-Community/actions/runs/40793763735)完成 Python 5,109 通过、78 跳过、0 失败，原生 DSH 110 通过、0 跳过，前端、Node、lint、类型检查、构建、wheel、新安装环境和安装态流程均通过。跳过项不计通过。

[后续 CI](https://github.com/lensnowovo/ProjectWatch-Community/actions/runs/40810809934)的 151 项 CI 契约通过；四个产品检查域按已核实的完整输入复用上述成功记录，没有重跑全部产品检查。最终必需检查通过，不把重跑次数累计为独立覆盖。

R4 wheel 与安装包内产品文件已核对；实际嵌入式 Python 下的导入、旧库升级、重复打开及托盘启动/复开/正常退出通过。12 项隔离安装器生命周期检查通过，标准安装器 Defender 扫描未发现威胁。安装态 worker 使用合成模型回执；原生 DSH 使用真实进程和受控网关。这些检查没有替代真实搜索及收费模型的质量验收。

## 已知限制

- 真实模型语义质量、新闻发现时效、独立 Windows 用户首次使用和连续 48 小时观察尚未验证，不承诺所有项目的完整覆盖。
- 历史真实任务曾把不同产品的“已获注册证”和“进入创新审评通道”混写为“均获批”。本次没有真实模型测试证明该质量问题已经消除；审批、财务和订单等结论须核对原始依据。
- 宿主离线起止区间的持久记录与页面展示尚未实现，不能把任务恢复或问题休眠机制等同于这项能力。
- 正文处理上限为 60,000 字符，超限部分不承诺自动续读；结果不明的请求仍受原有恢复保护，不因长文而重放。
- 专门的操作系统休眠→唤醒验收尚未执行，与已验证的研究问题休眠、纠错唤醒机制分开。
- Windows 安装器和启动器未签名，可能出现系统信誉提示；不要关闭系统防护来安装。Mac 新版本暂缓，Windows ARM、Server 及其他系统未按本次用户包范围验收。
- API 模式需要自己的模型和搜索账号，调用可能收费；已有 Agent 模式取决于对应客户端连接、权限和运行方式，不等于持续在线的免费后台服务。
- 固定依赖审计无已知漏洞报告不保证绝对安全。部分原生上游构建来源仍有已披露的可复现性局限，见[安全复核](../release-security-review.md)；不将其描述为新增漏洞或自动许可失败。

## 使用、升级与反馈

按照 [Windows 使用指南](../windows-user-guide.md)安装。升级前等待任务结束、正常退出并备份；沿用原数据目录，不通过卸载删除数据。回退按指南保留匹配的旧程序与升级前备份，不让旧程序直接打开已迁移的新库。结果不明时保留回执并停止重试，不换入口重放可能已付费的请求。

[支持范围](../release-support-matrix.md)列出已验与未验平台；[反馈入口](../../SUPPORT.md)提供问题分类。不要提交 Key、真实 BP、数据库、完整配置或原始商业材料。自有代码适用 ProjectWatch 社区使用许可，第三方材料继续遵循原许可。
