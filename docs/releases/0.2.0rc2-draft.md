版本候选：0.2.0rc2。目标平台：Windows x64。Mac 暂缓，Intel 不在此次发布清单。

最终公开源码提交、tag 和下载地址仍待批准，不能对外提供假链接。

## 面向使用者的说明

ProjectWatch 在本机建立和持续更新公司档案，结合长期关联监控与临时研究。
Windows 用户包包含所需 Python、Node、DSH 与解析依赖，无需另装 Python 或打开终端。
API 模式需要自己的模型和搜索账号；第三方调用可能收费。已有 Agent 模式仍取决于
对应客户端连接、权限及运行方式，不等于永久在线的免费后台模型。

首次使用与升级步骤见 [Windows 使用指南](../windows-user-guide.md)。
升级前等待任务结束、正常退出并保留备份；继续使用原数据目录，不先卸载删除数据。
遇到 unknown 保留回执并停止重试，不能靠重新建任务或换搜索源绕过。

## 本轮收尾变更（验收结果以看板为准）

- 更新固定 Python、Node 与受影响的解析/前端/DSH 依赖，保留完整已有功能。
- 修复深层中文自选目录下，安装器漏解压长路径文件及内置 Python 导入深层模块的问题。
  安装失败保留诊断回执；不通过修改系统长路径策略、关闭防护或跳过文件哈希来安装。
- 升级与卸载继续保护独立的数据目录、配置、原件和暂停状态；运行中实例阻止覆盖，
  不强制结束任务。最终整包生命周期结果仍须在发布前核实。
- 补齐普通用户使用说明、三类反馈模板、维护流程及第三方来源材料。
- 修复安装态 DSH 插件的 Windows 扩展路径加载；补强订单标题/正文的数字口径校验，
  防止“在手及意向”混合合计丢失限定。旧错误记录不自动改写；真实质量复验尚未完成。

上述是候选变更说明，不代表独立首次使用、真实监控闭环或全部发行门槛已通过。

## 必须披露的边界

- 已发现关联理由将不同产品的“已获注册证”与“进入创新审评通道”混写为“均获批”。
  此问题尚未解决；重要审批、财务、订单和人物关系须核对原始依据，模型结论不直接用于投资决策。
- r14 的完整判断/修订、临时研究自然停止、新证据唤醒和非医疗样本尚未完成真实验收。
  不承诺所有项目均能自动跑通，不用其他版本或合成协议测试替代这些结果。
- 本次保留原架构，声称台账等新架构另行开发；不混入未冻结离线补丁。

- 自有启动器和安装器未购买代码签名证书；可能出现系统信誉提示，不关闭防护来安装。
- 本地 SQLite 是主支持路径；已有团队/PostgreSQL、容器解析等可选能力保留，
  按 [支持矩阵](../release-support-matrix.md) 披露实测与未覆盖项。
- 部分来源不可用、信息缺失和模型失败可能发生；不得把部分完成描述成全面覆盖。
- 自有代码按 ProjectWatch 社区使用许可提供，机构内部使用免费、对外商业服务需授权；
  这不是 OSI 批准的开源许可。第三方材料遵循原许可。
