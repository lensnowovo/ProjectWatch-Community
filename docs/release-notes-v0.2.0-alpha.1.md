# ProjectWatch v0.2.0-alpha.1

首个完整开发者预览版。公开仓库从干净的初始提交开始，不包含开发历史、账号或业务数据。

## 包含什么

- 输入公司名或上传 BP，建立个人项目监控。
- 内部资料解析与版本记录；公司、竞品、行业、政策及研究线索跟踪。
- 竞争位置、技术路线、行业环境、问题证据与内外对照分析。
- React 界面、API/MCP 接口与项目级 Agent 授权写回。
- 任务状态、用量记录、暂停与恢复、未知付费结果保护。
- 备份恢复、源码更新检查与有本地定制时的 Agent 交接。

已有分析源码、提示词和规则随本版提供，不需要另一个私有分析包。

## 安装与升级

推荐 Windows x64、Python 3.12；源码开发另需 Git、Node.js 22+。
按 [开发指南](developer-quickstart.md) 安装。模型、搜索和商业数据服务使用自己的账号与额度，软件不附送 Key。

Release 提供源码 ZIP、Python wheel 和 SHA256SUMS.txt。wheel 包含已构建界面，但不捆绑 Python 和第三方依赖；请安装到独立虚拟环境。
源码 ZIP 不含 Git 历史；需要 Git 更新流程时请克隆公开仓库。升级前验证备份，勿直接覆盖唯一数据目录。

本次为预发布标签，更新器的稳定版本通道不会自动安装它。已有本地定制请交由 Agent 合并，不强制覆盖。

## 许可与边界

自有代码采用 ProjectWatch 社区使用许可 1.0：机构内部自用免费，对外商业服务须取得授权。
这是 source-available 项目，不宣称 OSI 开源；第三方代码和字体保留原有许可。商业授权及安全联系：lensnowovo@gmail.com。

这是开发者预览，不是多租户云服务，也不保证公开信息完整或模型判断准确。仅在本机运行，不直接暴露公网。
更多限制见 [已知边界](developer-known-limitations.md)。反馈请提供版本和脱敏复现，勿上传 Key、真实 BP 或数据库。
