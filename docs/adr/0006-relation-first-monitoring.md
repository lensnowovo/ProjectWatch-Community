# ADR-0006：关联监控为主干，问题研究为临时分支

日期：2026-10-21。状态：Accepted（用户同意方向；实现先在隔离环境验证）。

## 背景

问题台账适合专题研究，但不应成为长期监控的唯一组织方式。
“公司采用某技术路线，所以监控该路线”不以回答某个问题为结束条件。
旧的 topic/event 探索生命周期若同时承担长期关联，会混淆停止、唤醒与持续采集。

## 决定

在既有计划条目上增加显式角色和关联目标，复用 DSH、证据存储、调度与历史。
长期关联不参与临时专题的无增益停止及回答退出。研究分支可独立停止与唤醒。
旧条目保持原语义；新增关联需理由、来源、类型、目标和可执行检索词。
不引入独立图数据库，不只依赖提示词约束。

## 影响

优点：保留功能和旧数据；调度可区分持续监控和有界研究；能够解释关注原因。
代价：接口暂时并存三类条目；旧范围需以后逐项审阅；字面目标路由可能漏掉别名。
模型引用校验不证明关系语义正确，真实发现质量仍需后续授权实验。
本决定调整问题台账的产品地位，不取消既有研究、证据包和人的结论。

## 验证与回退

离线验证新旧兼容、关联去重、路由、停止隔离、持久恢复与新证据唤醒。
不更改当前安装版；回退代码不删除新增元数据和既有事实。
发布、安装版升级、付费实验分别等待用户授权。
