推定 ProjectWatch 使用了这些额外资源。

工程上的发行范围据此限定为完整应用及其实现源码，**不提供 React Bits 独立组件
下载、组件 SDK、模板集合或相似工具服务**。这是根据用途和文本作出的范围判断，
不是上游对 ProjectWatch 的个别书面批准；完整源码发行的界限仍在最终审阅中明确
列出，不能用“用户说先不管”作为通过证据。当前原始许可不随本次核查擅自替换。

## 最终分发必须一起核对

1. 安装器实际携带原始许可、补件和模型说明；清单不能只来自开发环境。
2. 对应源码附件与构建说明可下载，且与实际固定依赖版本匹配。
3. 自有许可中的商业授权不覆盖第三方组件、模型、服务账号和数据。
4. 不宣传为无条件 OSI 开源；不把完整应用发行扩大为独立第三方组件再授权。
5. 对未取得进一步确认的范围如实披露，由维护者在精确发行清单上确认，不自动发布。
