# Bundled fonts

- `noto-serif-sc-chinese-simplified-600-normal.woff2` — Noto Serif SC (weight 600, Chinese Simplified subset from @fontsource/noto-serif-sc 5.3.0). Upstream attribution: Google Inc.; see the unmodified OFL-noto-serif-sc.txt. SIL Open Font License 1.1.
- `newsreader-latin-wght-normal.woff2` — Newsreader variable (Latin subset from @fontsource-variable/newsreader 5.3.0). Copyright 2020 The Newsreader Project Authors. SIL Open Font License 1.1.

The complete license texts shipped by the Fontsource packages are included in
`OFL-noto-serif-sc.txt` and `OFL-newsreader.txt`.

On 2026-10-18 both bundled font files and license texts matched the version-pinned
npm package files served by jsDelivr. See docs/releases/2026-10-18-security-and-rights.md
for hashes and the distinction between individual-file comparison and full archive verification.

Font notices and the React Bits license are also copied into the built UI at
`assets/THIRD-PARTY-LICENSES.txt`, so installed wheels retain these notices.
